# Первое решшение:
`permutations` дает n! перестановок, а `is_valid` проверяет каждую за n^2 итого : O(n! * n^2)

# Второе решение
`backtracking` рекурсивно дает в худшем случае n! (на первой строке n решений, на второй n - 3 ... <= n!), а далее все проверки стоят где-то line * n ~ n^2. тоесть решение занимает O(n! * n^2).

# Третье решение
из-за словаря количество решений для любых возможных случаев находится за O(1)
